# bitombang.com

[bitombang.com](https://bitombang.com) is a minimalist photography portfolio built around an everyday-photography collection. It presents a clean, distraction-free gallery where each frame documents places, friends, and moments that matter — the kind of quiet, honest images where almost everything happens before the shutter.

## My Role

I built the project end to end as a solo developer, from design through content workflow and deployment:

- **Design** — a stripped-back, image-first layout that keeps the focus on the photographs, with a simple menu, a collection gallery, and an about page.
- **Frontend** — built the static site with Astro for fast, lightweight pages that load quickly on any device.
- **Content workflow** — set up Decap CMS so the gallery and pages can be edited directly, without touching code, making it easy to add or reorder photos over time.
- **Media pipeline** — integrated Cloudinary to host, optimize, and deliver images responsively, keeping the gallery sharp while staying fast.
- **Deployment** — handled the production build, domain setup, and releases.

## Tech Stack

- **Astro** — static-site framework for a fast, image-first portfolio.
- **Decap CMS** — Git-based content management for editing the gallery and pages.
- **Cloudinary** — image hosting, optimization, and responsive delivery.

The project is live at [bitombang.com](https://bitombang.com).
