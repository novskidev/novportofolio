## Why it is in my toolbox

I wanted an agent that could live on my server permanently without making me worry about resources. OpenClaw used ~396 MB of RAM on the same box; Hermes fit my setup and my workflow better.

## How I use it

- Chatting through Telegram while it reads files and runs commands on the server
- Scheduled jobs: backups, snapshots, uptime checks, with Discord alerts on failure
- Content drafting and post scheduling
- Remembering preferences and server details across sessions
