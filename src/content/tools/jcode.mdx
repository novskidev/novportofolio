## Why it is in my toolbox

I bounced between coding agents for a long time. Jcode is the first one that made me stop looking. The short version: it is cheap to run, fast to start, and the harness around the model does real work.

## How I use it

- Multiple sessions in parallel for separate tasks in the same repo
- Long sessions where the warm prompt cache keeps cost and latency down
- Anything where I want the agent to verify its work before claiming it is done

## Numbers I measured

| Tool        | RAM per extra session |

| Jcode       | ~10.4 MB              |
| Codex CLI   | ~21.6 MB              |
