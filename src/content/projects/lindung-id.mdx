# Lindung.id

[Lindung.id](https://lindung.id) is a motorcycle rental web app based in Bandung, Indonesia. It lets customers browse available units and book rentals online, while owners manage bookings and their fleet from the same platform.

## My Role

I owned the product end to end as a solo developer:

- **Product requirements (PRD)** — defined the scope, user flows, and feature specifications for the rental workflow: browsing units, checking availability, booking, and order management.
- **Design system** — built a consistent component library and visual language (typography, color tokens, layout patterns) used across the storefront and admin views.
- **Deployment** — set up the production pipeline on Vercel with continuous deployment from the repository, environment configuration, and domain setup.
- **Testing** — verified core booking and management flows through structured manual testing before every release.

## Tech Stack

- **React.js** — component-driven UI for the customer-facing storefront and admin flows.
- **Supabase** — PostgreSQL database, authentication, and API layer.
- **Vercel** — hosting and continuous deployment.

The project is live at [lindung.id](https://lindung.id).
